# Telegram-бот для Instagram

Бот принимает одну ссылку на публичный пост или Reels, получает первый доступный
файл через KKInstagram/KKClip и отправляет его в тот же Telegram-чат.

## Что поддерживается

- `https://www.instagram.com/p/.../` — фото, видео или первый элемент карусели;
- `https://www.instagram.com/reel/.../` — Reels;
- параметры вида `?igsh=...` безопасно удаляются перед обработкой.

Приватные публикации намеренно не поддерживаются. Сторонний сервис обычно
возвращает только один файл, поэтому карусель может быть неполной. Cookies и
пароли пользователей бот не принимает.

## Архитектура

```text
Telegram handler
  → строгая проверка URL
  → ограничитель очереди, частоты и повторных запросов
  → KKInstagram/KKClip в отдельном процессе с жёстким тайм-аутом
  → проверенные HTTPS-переходы до прямого Instagram CDN
  → временный каталог на один запрос
  → проверка CDN-адресов, MIME и размеров
  → одиночное фото или видео
  → гарантированное удаление временного каталога
```

Исходная ссылка преобразуется во внутренний адрес KKInstagram. Бот проверяет
каждый HTTPS-переход и самостоятельно загружает только прямой файл с разрешённого
Instagram CDN. KKInstagram не предоставляет надёжный список элементов карусели,
поэтому бот получает только первый доступный элемент и сообщает об этом в подписи.

## Запуск

Требуется Python 3.11 или новее.

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
python -m app
```

Для Linux/macOS отличается только активация окружения:

```bash
source venv/bin/activate
```

В корневом `.env` должен быть токен, полученный у BotFather:

```dotenv
BOT_TOKEN = 123456789:замените_на_настоящий_токен
```

Остальные настройки и безопасные значения по умолчанию перечислены в
`.env.example`.

## Проверки

```powershell
pytest
ruff check .
```

Сетевой тест с настоящим Instagram намеренно не входит в автоматический набор:
доступность и формат ответов стороннего сервиса могут меняться.

Для ручной проверки конкретной публичной ссылки без запуска Telegram:

```powershell
python scripts/smoke_instagram.py "https://www.instagram.com/reel/КОД/"
```

Скрипт выводит только количество, типы и размеры временно загруженных файлов.

## Ограничения

Telegram Cloud Bot API принимает фото до 10 МБ и прочие загружаемые файлы до
50 МБ; в проекте оставлен небольшой запас. Файл больше лимита не отправляется.

Для публичного или нагруженного сервиса понадобятся очередь заданий, отдельные
воркеры и метрики.

KKInstagram/KKClip — сторонний сервис, не связанный с проектом. При срабатывании
резервного пути он видит публичный адрес запрошенной публикации. Доступность и
формат ответов этого сервиса могут измениться без предупреждения.

## Правомерное использование

Публичная доступность публикации не означает автоматического разрешения на её
копирование. Используйте бот только для собственных материалов либо при наличии
разрешения или другого законного основания. Проект не связан с Instagram или Meta.

Полезные первичные источники:

- [Telegram Bot API: отправка файлов](https://core.telegram.org/bots/api#sending-files).
