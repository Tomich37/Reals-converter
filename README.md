# Telegram-бот для Instagram

Бот принимает одну ссылку на публичный пост или Reels, скачивает фото, видео
или карусель и отправляет содержимое в тот же Telegram-чат.

## Что поддерживается

- `https://www.instagram.com/p/.../` — фото, видео и смешанные карусели;
- `https://www.instagram.com/reel/.../` — Reels;
- до 10 медиафайлов в одной публикации;
- параметры вида `?igsh=...` безопасно удаляются перед обработкой.

Приватные публикации и материалы, для которых Instagram требует авторизацию,
намеренно не поддерживаются. Cookies и пароли пользователей бот не принимает.

## Архитектура

```text
Telegram handler
  → строгая проверка URL
  → ограничитель очереди, частоты и повторных запросов
  → Instaloader в отдельном процессе с жёстким тайм-аутом
  → временный каталог на один запрос
  → проверка CDN-адресов, MIME и размеров
  → одиночное медиа или Telegram-альбом
  → гарантированное удаление временного каталога
```

`Instaloader` выбран вместо одного `yt-dlp`, потому что публикация Instagram
может состоять не только из видео, но и из фотографий или смешанной карусели.

## Запуск

Требуется Python 3.11 или новее.

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
python -m app
```

Для Linux/macOS отличается только активация окружения:

```bash
source venv/bin/activate
```

В корневом `.env` должен быть токен, полученный у BotFather:

```dotenv
BOT_TOKEN = 123456789:замените_на_настоящий_токен
```

Остальные настройки и безопасные значения по умолчанию перечислены в
`.env.example`.

## Проверки

```powershell
pytest
ruff check .
```

Сетевой тест с настоящим Instagram намеренно не входит в автоматический набор:
Instagram регулярно меняет ограничения и может временно требовать вход даже для
публичных публикаций.

Для ручной проверки конкретной публичной ссылки без запуска Telegram:

```powershell
python scripts/smoke_instagram.py "https://www.instagram.com/reel/КОД/"
```

Скрипт выводит только количество, типы и размеры временно загруженных файлов.

## Ограничения

Telegram Cloud Bot API принимает фото до 10 МБ и прочие загружаемые файлы до
50 МБ; в проекте оставлен небольшой запас. Альбом содержит от 2 до 10 элементов.
Файл больше лимита не отправляется.

Instagram может ограничить анонимные запросы. Для публичного или нагруженного
сервиса понадобятся очередь заданий, отдельные воркеры, метрики и согласованный
с Meta способ доступа.

## Правомерное использование

Публичная доступность публикации не означает автоматического разрешения на её
копирование. Используйте бот только для собственных материалов либо при наличии
разрешения или другого законного основания. Проект не связан с Instagram или Meta.

Полезные первичные источники:

- [Telegram Bot API: альбомы](https://core.telegram.org/bots/api#sendmediagroup);
